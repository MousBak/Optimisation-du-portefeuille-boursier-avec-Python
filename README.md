# Optimisation de portefeuille boursier avec Python

> Financial Analytics / Portfolio Optimization

## Vue d'ensemble

Projet d'optimisation de portefeuille financier avec Python. Le notebook illustre comment analyser des actifs, comparer rendement et risque, puis construire une allocation plus équilibrée.

## Objectifs du projet

- Analyser les performances historiques d’actifs financiers.
- Mesurer le couple rendement/risque.
- Comparer plusieurs allocations possibles.
- Présenter une logique d’optimisation de portefeuille.

## Démarche

- Préparation des séries financières.
- Calcul de rendements et volatilité.
- Comparaison d’actifs ou portefeuilles.
- Visualisation des résultats et interprétation.

## Stack technique

- Python
- Pandas

- Matplotlib
- Finance
- Jupyter Notebook
